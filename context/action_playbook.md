# Action Playbook (v1.0)

> **본 문서는 이커머스 CS 일반 참조 모델(Reference Model)이며, 특정 기업의 실제 대응 매뉴얼이 아니다.**
> 실행안은 관찰된 원인([cause_taxonomy.md](cause_taxonomy.md))에 대응하는 **일반적으로 가능한 조치**를 제시한다.

## 작성 원칙

| # | 원칙 | 적용 |
|---|---|---|
| 1 | 원인 대응 | 각 Action은 Cause 코드(A-c1 등)에 연결 |
| 2 | 참조 모델 선언 | 상단 고지 |
| 3 | 성과지표는 사전에서만 | Success Metric은 [metric_dictionary.md](metric_dictionary.md)에 정의된 것만 (SPEC §9) |
| 4 | 데이터 한계 반영 | "내부 협의 필요" 항목 명시 |
| 5 | 2계층 정합 | 대분류 A~J 기준 |

**대응 유형 태그:** `[프로세스]` `[시스템]` `[콘텐츠/FAQ]` `[협력사관리]` `[정책]`

> **사용법 (Recommendation 단계):** LLM은 이 목록에서 Action을 선택하고, 기대효과(Frequency 기반)와 Success Metric(사전에서 선택)을 붙인다. 목록에 없는 조치를 지어내지 않는다.

## 대응 유형별 요약 (실행 우선순위 판단용)

| 유형 | 특징 | 대표 Action |

| `[콘텐츠/FAQ]` | **가장 빠르고 저비용.** 인입을 사전 예방 | E-a1, J-a1, I-a1, G-a1 |
