# Metric Dictionary (v1.0)

> **본 문서는 이커머스 CS 일반 참조 모델(Reference Model)이며, 특정 기업의 실제 KPI 체계가 아니다.**
> 지표는 **1차(VOC 관측)**와 **2차(사업)**로 나눈다. 본 MVP는 1차만 측정하고, 2차는 연결 지점만 명시한다(SPEC §8).

## 작성 원칙

| # | 원칙 | 적용 |
|---|---|---|
| 1 | 측정 가능성 명시 | 1차=본 데이터로 측정 가능 / 2차=사업 데이터 필요 |
| 2 | 참조 모델 선언 | 상단 고지 |
| 3 | Recommendation 제약 | Success Metric은 **1차 지표에서만** 선택 (SPEC §9) |
| 4 | 2계층 연결 | 각 1차 지표에 대응하는 2차 지표 병기 |

---

## 1. 1차 지표 — VOC 관측 (본 MVP에서 측정)

| 지표 | 정의 | 산출 | 대응 2차 지표(연결) |
|---|---|---|---|
| **토픽 VOC 비중** | 특정 토픽이 전체 VOC에서 차지하는 % | 토픽 VOC수 ÷ 전체 VOC수 × 100 | CS 처리 건수·비용 |
| **부정 감정 비율** | 토픽 내 Negative+Severe 비율 | 부정 VOC ÷ 토픽 VOC | CSAT, 이탈률 |
| **토픽 심각도(S_score)** | 감정점수 평균 0~100 | SPEC §6.2 | NPS, 이탈률 |
| **토픽 추세(Trend)** | 이전 기간 대비 비중 변화율 | SPEC §6.3 | 문제 확산 속도 |
| **재문의율** | 동일 이슈 반복 인입 정도 | (근사) 동일 토픽 고빈도 표현 | FCR(최초해결률) |
| **사유 확인율** | 중분류가 배정된 비율 (null 아님) | 중분류 有 ÷ 토픽 VOC | 상담 품질 |
| **자가해결 전환 가능 비중** | E·J·G 등 FAQ성 문의 비중 | 해당 토픽 VOC 합 ÷ 전체 | 셀프서비스율, 인당 문의량 |

> `사유 확인율`과 `자가해결 전환 가능 비중`은 이 프로젝트에서 새로 도출된 지표다. 전자는 상담 프로세스, 후자는 셀프서비스 개선의 직접 신호다.

---

## 2. 2차 지표 — 사업 (본 MVP 범위 밖, 연결만 명시)

> 이 지표들은 매출·이탈·비용 등 **사업 데이터가 필요**하여 본 데모에서는 측정하지 않는다. 유관부서가 1차 지표와 결합해 산출한다(SPEC §1-A 부서 경계).

| 2차 지표 | 정의 | 필요 데이터 |
|---|---|---|
| CS 처리 건수·비용 | 문의 1건당 처리 비용 × 건수 | CS 운영 데이터 |
| CSAT / NPS | 고객 만족도·추천지수 | 설문 데이터 |
| 이탈률(Churn) | 이슈 경험 고객의 이탈 비율 | CRM·구매 데이터 |
| 재구매율 | 이슈 처리 후 재구매 비율 | 구매 데이터 |
| FCR (최초 해결률) | 첫 상담에서 해결된 비율 | 상담 이력 |
| 셀프서비스율 | FAQ·챗봇으로 해결된 비율 | 채널 데이터 |
| 반품·환불 비용 | 반품 물류·환불 처리 비용 | 물류·재무 데이터 |

---

## 3. 연결 논리 (1차 → 2차)

Recommendation의 Expected Effect는 1차 지표로 정량화하고(SPEC §9), 그 개선이 어떤 2차 지표로 이어지는지 화살표로 명시한다.

```
배송 지연 VOC 비중 ↓  ──►  CS 처리 건수·비용 ↓, 이탈률 ↓
반품 처리지연 VOC ↓   ──►  CSAT ↑, 재구매율 ↑
자가해결 전환 비중 활용 ──►  셀프서비스율 ↑, 인당 문의량 ↓ ──► CS 비용 ↓
사유 확인율 ↑         ──►  FCR ↑
```

**예시 (배송 지연):**
> Expected Effect: "배송 지연이 전체 VOC의 X%. 개선 시 VOC 인입 X% 감소 기대"
> Success Metric(1차): 배송 관련 VOC 비중
> 연결(2차): CS 처리비용 절감, 이탈 방어 — *유관부서가 산출*

## 4. Priority 공식 지표 (참조)

Priority = 0.4·F + 0.4·S + 0.2·T (SPEC §6.4). 세 입력 모두 위 1차 지표에서 나온다.
- F ← 토픽 VOC 비중 (정규화)
- S ← 토픽 심각도(S_score)
- T ← 토픽 추세(Trend)

> Business Impact(B)는 2차 지표라 공식에서 제외했다(SPEC §1-A). 사업 데이터 확보 시 `0.3F+0.3S+0.2T+0.2B`로 확장 가능.
